# Study × VocabMaster：歷屆生字第一版

使用者：高二、龍騰課本，目標為段考與學測，優先補單字量。

## 第一版範圍與執行順序

1. 離線讀取英語文 Markdown 的「題目內容」，與現有高中分級詞庫比對；不讀答案、難度標籤或延伸連結。按不同試卷出現數計算，避免同一文章拆題膨脹頻率。保留原始檔案名稱與題目片段。字形只做精確比對，不猜測詞根或翻譯。
2. word 新增獨立的歷屆生字頁與小型 Blueprint。預設展示第一、二級；可切換更高級、搜尋與查看原題片段。詞義標明為既有詞庫釋義，不保證是該題語境的唯一意思。
3. 登入後選擇不熟的字，存入現有 words 表的「歷屆英文」資料夾及目前 owner_id；重複收藏保持原進度。專用複習只取本人該資料夾，先回想再揭曉，按不記得／吃力／記得沿用 schedule_review。出處仍由可重建題庫依英文單字對應。
4. Study 側欄連到 word 的歷屆生字頁，word 頁連回 Study。兩站各自使用既有登入；不在網址傳 JWT。第一版為「題庫素材與複習入口整合」，尚不提供 Study 英文自動判分或作答中點字收藏。

## 邊界

本版不變更 DB schema、既有 API 契約、auth payload 或部署設定。新增 /exam-vocabulary 及 /api/exam-vocabulary 專用端點；新增端點要求登入，寫入還驗證 CSRF 或 JWT。本人收藏的檢查不可省略，即使目前只有一位使用者。既有單字與 SRS 排程原樣保留。

龍騰課本單字尚未取得，不能把校內歷屆試題詞彙標成龍騰課次範圍。頻率只代表本地試卷文字出現，不能宣稱是學測出題機率。片段可能缺文章，不能當完整試題或提供自動判分。

## 驗證與發布

離線抽取測試：不納入答案／延伸連結、同卷去重、無詞庫命中略過、輸出穩定。
API：未登入拒絕、CSRF、重複收藏、跨帳號隔離、兩種 interval 欄位、複習到期。
瀏覽器：篩字、揭曉、收藏、複習、空狀態與錯誤提示，手機寬度無水平溢出。
執行 word pytest、Study build；只提交本次變更，不包含先前 web.py 修改或環境檔。公開部署另以完整執行依賴與啟動環境檢查後進行，本次先交付可執行且驗證的本地版本。

## 本地驗證結果

- 產物：2,969 個與高中分級詞庫精確匹配的候選字；文件 1,124，疑似只有選項 519，標記未附簡答 462。以上是文字規則檢查，非人工題目審核。
- word 測試共 22 項通過。新頁面在 390px 手機視窗完成：搜尋 decision → 揭曉 → 收藏 → 到期複習 → 評分 → 再查無到期項目。未發現 JS 錯誤或水平溢出。
- 登入後 API 傳送完整候選清單（約 3 MB），第一版適合個人使用，未做大量使用者效能測試。
- 候選字不等於新學會的字；本版保存自行選擇的生字與 SRS 排程，不宣稱測得詞彙量或熟練度。
- 專用端點沿用目前 word 的登入相容層；舊 checkout 無 JWT helper 時只接受 session + CSRF。既有尚未提交的 SSO 改動不包含在本次提交。
